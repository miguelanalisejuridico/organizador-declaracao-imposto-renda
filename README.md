# Organizador de Declaração de Imposto de Renda — Excel

## Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático da plataforma DIO, com o objetivo de aplicar conhecimentos de Excel na criação de uma ferramenta para organizar e centralizar informações relacionadas à declaração do Imposto de Renda.

A planilha utiliza recursos nativos do Excel para facilitar o preenchimento, a consulta e a organização dos dados.

## Objetivos

- Organizar informações do titular.
- Centralizar informações de informes bancários.
- Registrar entradas e saídas financeiras.
- Facilitar o preenchimento por meio de listas suspensas.
- Simplificar a navegação entre as abas.
- Automatizar cálculos básicos utilizando fórmulas.

## Estrutura da planilha

### Aba TITULAR
Área destinada à organização dos dados cadastrais do titular.

### Aba INFORMES
Área destinada ao registro de informações bancárias e valores dos informes, com fórmulas para totalização.

### Aba NOTAS
Área destinada ao registro de movimentações financeiras, com datas, categorias e valores de entradas e saídas.


## Recursos utilizados

- Microsoft Excel.
- Links para navegação entre as abas.
- Listas suspensas.
- Fórmulas básicas para cálculos e totalizações.
- Organização das informações em diferentes abas.

## Como utilizar

1. Baixe o arquivo Excel disponível neste repositório.
2. Abra a planilha em uma versão compatível do Microsoft Excel.
3. Utilize os links para navegar entre as abas.
4. Preencha os campos conforme as opções disponíveis.
5. Confira os valores e os resultados calculados.

## Aprendizados

O desenvolvimento deste projeto permitiu praticar a organização de dados, o uso de fórmulas, a criação de listas suspensas e a construção de uma navegação intuitiva no Excel.

## Observação

Esta ferramenta possui finalidade organizacional e educacional. Ela não substitui o programa oficial da Receita Federal nem garante, por si só, a correção ou a completude das informações necessárias à declaração do Imposto de Renda.
